# v0.8.9 — v0.8.0 closeout cleanup

> **Status:** Shipped — the final v0.8.x PR into `v0.8.0`. `.meta/VERSION` →
> `0.8.9` (release-marked in this PR, closing the cycle).
> **Depends on:** v0.8.7 (regime chart), v0.8.8 (analytics tabs), v0.7.5 (the
> correlation Benchmark/Regime controls), v0.8.4 (superlatives board).
> **Theme:** a grab-bag of five small, unrelated refinements to close out v0.8.0.

## Changes

1. **Drop the "Risk regime"** option from the Platform regime chart — remove its
   `REGIME_SPECS` entry + `NFCIRISK_TICKER` (from `REGIME_TICKERS` /
   `LEVEL_INDICATOR_MOCK` / the constant) and the dead `change_tercile` branch in
   `builder._regime_indicator`. Regime types: Volatility / Trend / Rate-level.
2. **Correlation heatmap** (Multi-Strategy): add the benchmark to the matrix
   whenever the **Benchmark** checkbox is ticked (was only on the nested
   **Regime** check). New middle branch in `builder._render_heatmap` reusing
   `regime_corr_matrix(..., pct=1.0, include_benchmark=True)`.
3. **Superlatives:** drop the Most overbought / Most oversold (RSI) and Lowest
   VaR cards (`src/commentary.py`) → 19 → **16 cards** (8 best/worst pairs); drop
   the now-unused `rsi` / `historical_var` imports.
4. **Universe solutions:** `ARP_SOLUTION_VALUES` → `UNIVERSE_SOLUTION_VALUES` =
   `{arp, alternative risk premia, smart beta, risk management}` (plain `Beta`
   stays out; `risk management` is forward-compatible).
5. **Prune stale indices:** drop indices with no price movement over the trailing
   ~21 trading days (flat / empty / forward-filled-dead) via a new
   `stats.active_columns`; `meta_all` (everything fetched) is kept so a resumed
   ticker can return on Refresh.

## Non-goals

Layout/data cleanup only — no new charts, no new runtime deps, one BQL call per
session unchanged (the new indicators already rode the fetch; NFCIRISK is simply
dropped from it).
