# v0.7.1 — Platform factor scatter: 3D + asset-class colors

> **Status:** Shipped (PRs #90, #91 (recovered via #93)).
> executed against.
> **Depends on:** v0.7.0 (the Platform tab's factor-beta scatter, the
> `FACTOR_TICKERS` single-fetch wiring, and `src/stats/factors.py`).
> **Theme:** turn the Platform factor-beta scatter from a flat 2D plot into a
> **3D** factor cube with a third "Trend Exposure" axis, fix the asset-class
> coloring (today most markers render grey), and drop the chart's own title that
> duplicates the section header.

## 1. Summary & non-goals

The v0.7.0 factor scatter plots each strategy's β to the equity risk premium (x)
against its β to the term premium (y), one marker per strategy, colored by asset
class, under the shared **6M / 1Y / 3Y / 5Y** lookback selector. v0.7.1
refines it on three fronts:

1. **De-duplicate the title.** The chart carries its own in-figure title
   (`"Equity vs term-premium β — {lookback}"`) directly under the
   **"Factor exposures"** section header — visually redundant. Remove the chart
   title; let the section header stand alone.
2. **Add a third axis.** Promote the scatter to a **3D** plot whose z-axis is
   each strategy's β to **`BSLXAT Index`** (the Bloomberg cross-asset trend
   index), axis-labelled **"Trend Exposure"**.
3. **Fix the colors.** Asset-class markers should be distinctly colored, not
   grey (see §2).

**Non-goals (hard constraints):**

- **One BQL call per session stays.** The new `BSLXAT Index` factor ticker rides
  the existing single `fetch_prices(... + FACTOR_TICKERS)` call — **no second
  fetch**. The lookback toggle keeps re-slicing the cache only.
- **Multi-Strategy tab untouched.** This is a Platform-tab-only change.
- **No new chart for the third axis** — it is the same scatter, promoted to 3D.
- **ARP whole-catalog views keep excluding factor columns** (the new ticker is a
  factor, reindexed out of `arp_universe_prices` like the others).

## 2. Motivation (current state, with refs)

- **Title duplication** — `src/layout/platform.py` `_factor_beta_scatter` sets
  `_chart_layout(title="Equity vs term-premium β", …)`, and
  `src/layout/builder.py` re-sets it per lookback. The section header
  **"Factor exposures"** is rendered separately
  (`render_template("grid_header", …, text="Factor exposures")`), so the user
  sees the same idea twice.
- **Grey markers** — `src/layout/platform.py` `_update_factor_scatter` colors
  each asset-class trace via
  `ASSET_CLASS_COLORS.get(ac, ASSET_CLASS_FALLBACK_COLOR)`. But
  `src/style.py` `ASSET_CLASS_COLORS` is keyed `Macro / Equity / Rates /
  Credit`, while the catalog's actual `AssetClass` values (in
  `data/indexdb.json`) are **Equity, Fixed Income, Commodity, FX**. Only
  `Equity` matches; every other strategy falls through to
  `ASSET_CLASS_FALLBACK_COLOR = SLATE_400` (grey). So the legend looks mostly
  grey.
- **2D figure** — `_factor_beta_scatter` builds a `go.FigureWidget` of
  `go.Scatter` traces with `xaxis`/`yaxis` titles and a dashed zero crosshair
  via `_h_ref(0.0)` / `_v_ref(0.0)` (paper-referenced 2D shapes).
- **Factor plumbing** — `src/config.py` `FACTOR_TICKERS = [LONG_TREASURY_TICKER,
  SHORT_RATE_TICKER]`; `builder.py` dedupes `meta tickers + BENCHMARK_TICKERS +
  FACTOR_TICKERS` into one fetch. `src/stats/factors.py` exposes
  `equity_risk_premium` / `term_premium` (short-rate spreads) and `factor_beta`
  (a thin `ann_beta` wrapper over a daily factor-return series). The off-terminal
  mock (`src/bql_client.py`) is deterministic per ticker, so a new ticker is
  auto-covered.

## 3. Workstream A — De-duplicate the chart title

- Remove the in-figure title from `_factor_beta_scatter` (drop the `title=`
  arg / set empty) and remove the per-lookback `fig.layout.title.text = …`
  re-set in `builder.py`'s scatter render closure.
- Keep the **"Factor exposures"** section header. If lookback context is still
  wanted on-screen, fold the lookback label into that header text rather than
  re-introducing a chart title (optional, low priority).

## 4. Workstream B — 3D scatter with a Trend Exposure axis

- **Config:** add `TREND_TICKER = "BSLXAT Index"` and append it to
  `FACTOR_TICKERS` in `src/config.py`. It then rides the single fetch and is
  auto-mocked off-terminal.
- **Stats:** add a thin helper in `src/stats/factors.py` that returns the
  **daily return series** of the trend ticker (β is taken vs the BSLXAT *returns*
  directly — unlike ERP/term, this is **not** a short-rate spread). Re-export it
  from `src/stats/__init__.py`.
- **Scatter → 3D** in `src/layout/platform.py`:
  - Compute `z = factor_beta(rets, trend_returns, years)` alongside the existing
    x/y betas in `_update_factor_scatter`.
  - Switch the per-asset-class traces from `go.Scatter` to `go.Scatter3d`
    (`mode="markers"`, add `z=`, tune marker size for 3D).
  - In `_factor_beta_scatter`, move axis titles into a
    `scene=dict(xaxis=dict(title="Equity risk-premium β"), yaxis=dict(title=
    "Term-premium β"), zaxis=dict(title="Trend Exposure"))`.
  - Replace the 2D `_h_ref`/`_v_ref` zero crosshair (paper shapes don't apply to
    a 3D scene) with `zeroline=True` on each scene axis.
  - Keep one trace + legend entry per asset class.

## 5. Workstream C — Fix asset-class colors

- Rebase `src/style.py` `ASSET_CLASS_COLORS` onto the catalog's **real** asset
  classes — `Equity`, `Fixed Income`, `Commodity`, `FX` — each mapped to a
  distinct token (keep a sensible fallback for unknown classes).
- Re-verify every `ASSET_CLASS_COLORS` consumer (grep) so the re-key doesn't
  regress another view.
- *(Optional)* make the assignment robust to unseen asset classes via a
  categorical color cycle keyed on whatever classes are present, so future
  catalog additions also get a distinct color rather than the fallback.
