# v0.8.8 — Platform analytics tabs

> **Status:** In progress — branched off `v0.8.0-platform-analytics-tabs`
> (stacked on the v0.8.7 regime rework, PR #121). `.meta/VERSION` bump deferred
> to end-of-cycle release-marking.
> **Depends on:** v0.7.0/v0.7.1 (factor scatter), v0.8.x (sunburst), v0.8.5/v0.8.7
> (regime analysis) — all in `src/layout/platform.py` + `builder.py`.
> **Theme:** group the three Platform analytics charts into one boxed, tabbed
> card so the section reads as a clear unit and shares one lookback.

## 1. Summary & non-goals

The Platform tab stacked its three analytics charts vertically with scattered,
inconsistent controls (the sunburst had its own decoupled lookback). v0.8.8
turns them into a single **boxed "Platform analytics" card** of **inner
pill-tabs** — ordered **Sunburst → Regime analysis → Factor exposures** — that:

- **Share one lookback** — the existing `lookback_selector` (6M/1Y/3Y/5Y) drives
  all three; the sunburst's own `sb_lookback_dd` is removed and `_render_sunburst`
  reads the shared toggle.
- **Stack each tab's extra controls in a left-hand column** beside the chart
  (the chart flex-grows to fill the rest): Sunburst → Metric + Window; Regime →
  Type / Source (conditional) / Bucket; Factor → none (chart-only).
- **Box the group** with a token-driven `.bbg-card` (border + radius + surface +
  padding), mirroring the Multi-Strategy bordered panels — always visible.

**Non-goals (hard constraints):**

- **Layout-only** — no stats / data / BQL changes; the three render closures and
  `platform.py` factories/updaters are reused unchanged (figures mutate in place
  whether their tab is visible or not, so a tab swap is a free `.children` swap).
- **No new runtime deps**; reuse `_make_tab_button` / `_style_tab_button` and the
  top-level `_activate_tab` pattern.
- All-catalog grid + its ranking controls left as-is above the card; Multi-Strategy
  tab untouched.

## 2. Workstreams

- **A — Layout:** dismantle the standalone headers / `regime_section` /
  `sunburst_controls_row` / `lookback_row`; build `_analytics_tab(controls, fig)`,
  the 3 pills + `_activate_platform_tab`, and the `.bbg-card` analytics card;
  rewire `platform_panel` children to `[universe_header, z_controls_row,
  universe_grid, analytics_card]`.
- **B — Shared lookback:** drop `sb_lookback_dd`; `_render_sunburst` uses
  `lookback_selector.value`; add `_render_sunburst` to the shared lookback
  observer loop.
- **C — CSS:** add `.bbg-card` to `data/templates/app_css.html`.

## 3. Acceptance criteria

- Platform panel = grid group + one bordered `analytics_card`; the card holds a
  3-pill tab bar + the shared lookback on one row, then the swappable tab content.
- Sunburst (default) shows Metric + Window in a left column (no lookback);
  changing the **shared** lookback re-renders it.
- Regime tab shows Type / Source (conditional) / Bucket stacked; conditioning
  still works. Factor tab is chart-only.
- Switching tabs is instant; `ruff` + `black` + `pytest` green; CLAUDE.md +
  dev-map updated.
