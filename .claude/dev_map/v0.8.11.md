# v0.8.11 — Quant Z-Score window + commentary height

> **Status:** Shipped — a small follow-up patch into `v0.8.0`. `.meta/VERSION` →
> `0.8.11`.
> **Theme:** two small, independent UI refinements.

## Changes

1. **Quantitative Z-Score window** (`src/layout/builder.py`): add a `q_z_window`
   dropdown (`1W/1M/3M/6M`, default `1M`) beside the Z-Score base-metric dropdown
   in the Multi-Strategy Quantitative filter. It sets the lookback the base metric
   is computed over for the **cross-sectional** z (kept as-is, all 8 base metrics),
   **independent of the global Period**. `_quant_keep` recomputes the base metric
   over the chosen window via `quant_metrics_table(prices, z_bench, z_window/252,
   returns=rets)` (threading the base metric's benchmark for Beta/Treynor/Jensen),
   then `zscore_cross_section`. Wired into `quant_inputs` so it re-narrows live; no
   BQL, no new stats helper.
2. **Commentary height** (`data/templates/highlights_two_col.html`): halve each
   Key-Highlights card area `max-height:45vh → 22.5vh` (Superlatives grid + New
   Launches list) so the board is ~half as tall.
