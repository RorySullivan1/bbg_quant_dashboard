## 1. Summary & non-goals

The Platform tab's 3D factor-beta scatter (β to the equity risk premium / term
premium / trend factor) has no in-cloud zero reference — only thin per-axis
zerolines on the scene walls. v0.8.6 adds **three translucent `go.Mesh3d`
zero-reference planes** (x=0, y=0, z=0), sized to the point cloud, so the origin
is visible in every dimension.

**Non-goals (hard constraints):**

- **No analytics / data change** — the betas, asset-class coloring, hover, and
  lookback behavior are unchanged; this is a pure visual overlay.
- **No new runtime dependencies** (plotly `go.Mesh3d` only); **no BQL**.
- **Treemap, Multi-Strategy tab, and the rest of Platform untouched.**
- Slated to ship **ahead of v0.8.5 (Regime Analysis)**, which is unrelated.

## 2. Motivation

In 3D it's hard to tell where each β crosses zero. A faint plane through the
origin on each axis turns "is this strategy long or short the equity factor?"
into a glance instead of a mental rotation.

## 3. Current state (grounded, with refs)

- `_factor_beta_scatter()` / `_update_factor_scatter()` — `src/layout/platform.py`.
  The updater computes the per-strategy x/y/z betas into a `frame`, groups by
  asset class, and replaces traces inside `fig.batch_update()`
  (`fig.data = ()` + `fig.add_traces(...)`). Axis ranges auto-scale (no fixed
  ranges) and each `scene` axis already sets `zeroline=True`.
- No existing `go.Surface`/`go.Mesh3d` in `src/` — this introduces the first.

## 4. Workstream A — translucent zero planes

- Add `_zero_planes(frame)` + `_quad_mesh(...)` + `_axis_bounds(...)` and the
  `_ZERO_PLANE_OPACITY` constant to `src/layout/platform.py`. Each plane is a
  flat 4-vertex `go.Mesh3d` quad (two triangles) at a fixed 0 on its own axis,
  spanning the padded data bounds of the other two; `Color.CHART_AXIS` at
  `_ZERO_PLANE_OPACITY`, `showlegend=False`, `hoverinfo="skip"`.
- In `_update_factor_scatter`, add the planes before the markers in the existing
  `batch_update` (`fig.add_traces([*_zero_planes(frame), *traces])`). Empty/
  degenerate inputs unchanged (no planes → `fig.data == ()`).
