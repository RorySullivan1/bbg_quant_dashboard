# v0.7.3 — Platform treemap: 1-week color metric + title de-dup

> **Status:** Not started. Documentation only — the roadmap the v0.7.3 cycle is
> executed against.
> **Depends on:** v0.7.0 (the Platform treemap, `platform_treemap_frame`, and
> the shared lookback selector).
> **Theme:** retune the Platform treemap's color metric from a **1-month** to a
> **1-week** risk-adjusted return z-score, and drop the chart's own title that
> duplicates the section header.

## 1. Summary & non-goals

The Platform tab's treemap nests **asset class → theme → ticker**, with tiles
**sized by z(6M Sharpe, lookback)** and **colored by z(1M Sharpe, lookback)** on
a diverging colorscale, under the shared 6M / 1Y / 3Y / 5Y selector. v0.7.3
makes two small changes:

1. **Color by 1-week, not 1-month.** Change the color metric to
   **z(1W Sharpe, lookback)** so the coloring reflects the most recent
   risk-adjusted momentum. **Size stays z(6M Sharpe, lookback).**
2. **De-duplicate the title.** The treemap carries its own in-figure title
   (`"Risk-adjusted strength — {lookback}"`) directly under the
   **"Risk-adjusted strength map"** section header — redundant. Remove the chart
   title; let the section header stand alone.

(Sharpe is the risk-adjusted-return measure here — confirmed; only the **window**
shrinks 1M → 1W.)

**Non-goals (hard constraints):**

- **No BQL / fetch change.** Both z-scores recompute live from the
  already-fetched cache via `platform_treemap_frame`; the lookback toggle
  re-slices the cache only.
- **Hierarchy, sizing semantics, colorscale, and the section header stay.**
- **Multi-Strategy tab untouched.**

## 2. Motivation (current state, with refs)

- `src/stats/factors.py` `platform_treemap_frame` computes
  `size_z = rolling_metric_zscore(..., window=HALF_YEAR_WINDOW, ...)` and
  `color_z = rolling_metric_zscore(..., window=MONTH_WINDOW, ...)` — i.e. color
  is currently the **1-month** Sharpe z-score.
- `src/config.py` defines window constants (`MONTH_WINDOW`, `HALF_YEAR_WINDOW`,
  …) but **no** one-week window.
- `src/layout/platform.py` `_treemap` sets `_chart_layout(title="Risk-adjusted
  strength", …)`, re-set per lookback in `builder.py`; the treemap hover
  (`_TREEMAP_HOVER`) and colorbar title read **"z(1M Sharpe)"**. The section
  header **"Risk-adjusted strength map"** is rendered separately.

## 3. Workstream A — Switch the color metric to 1-week

- Add a `WEEK_WINDOW` constant (≈ 5 trading days) to `src/config.py`, alongside
  `MONTH_WINDOW` / `HALF_YEAR_WINDOW`.
- In `platform_treemap_frame`, compute `color_z` with
  `rolling_metric_zscore(..., metric="sharpe", window=WEEK_WINDOW,
  zscore_window=lookback)`. Leave `size_z` on `HALF_YEAR_WINDOW` (z(6M Sharpe)).
- Update the treemap **hover** (`_TREEMAP_HOVER`) and **colorbar title** text in
  `src/layout/platform.py` from `z(1M Sharpe)` → **`z(1W Sharpe)`**.

## 4. Workstream B — De-duplicate the chart title

- Remove the in-figure title from `_treemap` (drop `title=` / set empty) and the
  per-lookback `fig.layout.title.text = …` re-set in `builder.py`'s treemap
  render closure.
- Keep the **"Risk-adjusted strength map"** section header; verify the size
  metric stays lookback-aware (it flows from the shared selector unchanged).
