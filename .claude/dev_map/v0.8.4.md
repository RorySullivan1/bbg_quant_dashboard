## 1. Summary & non-goals

Replace the current superlative set — mostly one-sided "best" cards driven by
raw magnitude (`period_return`, OLS `trend_strength`, `ma_spread`,
`ann_volatility`) plus subjective picks (Best diversifier / Biggest turnaround /
Most resilient) — with a **paired best/worst** board built from technical
indicators, where each scale-dependent metric is ranked **cross-asset-neutrally**
by an asset-class-demeaned z-score.

**Non-goals (hard constraints):**

- **Whole-catalog (ARP) only** and **no new BQL** — computes from the
  already-fetched `arp_universe_prices`, exactly like today.
- **No layout / renderer change.** `_render_superlative_cards`
  (`src/layout/html.py`) already renders arbitrary
  `{label, value, name, ticker, sentiment, description}` cards; the
  45vh-scroll container, the `superlative_window` toggle, and
  `_render_highlights_panel` are reused unchanged. (More cards is fine — the
  panel already scrolls.)
- **No new runtime dependencies** (numpy/pandas only).
- **Multi-Strategy tab and New Launches panel untouched.**

## 2. Motivation

Today's board (v0.8.x) leans **positive and magnitude-biased**: most cards are
green "best" superlatives, and the scale-dependent ones (return, vol, drawdown,
MA-spread) tend to be won by whichever asset class is structurally highest-vol
(commodities loudest, bonds quietest), so the same families dominate every
window. A desk wants **both extremes**, **behaviour/persistence** measures
(does it trend or mean-revert? how fast does it recover?), and a depiction that
is **fair across asset classes**.

## 4. Indicator taxonomy

"Norm?" = the card's winner is chosen by the **asset-class-demeaned
cross-sectional z-score** of the metric (the card still shows the **raw**
value); "raw" = compared directly (already bounded/unitless).

| Category | Metric | Cards | New stat? | Norm? | Sentiment |
|---|---|---|---|---|---|
| Performance | `period_return` | Best / Worst performer | reuse | **z** | +/− |
| Trend (persistence) | lag-1 return **autocorrelation** | Most trending / Most mean-reverting | **new** `return_autocorr` | raw | neutral |
| Run duration | up / down streak | Longest bull run / Longest bear run | reuse `longest_up_streak` / `longest_down_streak` | raw | +/− |
| RSI | `rsi` (14d, fixed lookback) | Most overbought / Most oversold | reuse | raw | neutral |
| Extended | **MACD** histogram (12/26/9, ÷ price) | Most extended up / Most extended down | **new** `macd_histogram` | **z** | +/− |
| Drawdown / drawup | `max_drawdown` / **max drawup** | Largest drawup / Deepest drawdown | **new** `max_drawup` | **z** | +/− |
| Tail risk | `historical_var` | **Lowest VaR** (single) | reuse | **z** | + |
| Recovery | trough → prior-peak days | **Fastest recovery** (single) | **new** `recovery_days` | raw | + |
| Risk-adjusted | `ann_sharpe` | Best / Worst risk-adjusted | reuse | **z** | +/− |
| Win rate | % up days | Highest / Lowest win rate | **new** `win_rate` | raw | +/− |
| Skewness | daily-return skew | Most positive skew / Most negative skew | new `return_skew` (or reuse `return_distribution_stats`) | raw | +/− |

≈ **20 cards** as designed — 9 best/worst pairs + 2 singles (Lowest VaR, Fastest
recovery). **Shipped as 19:** the *Fastest recovery* card was dropped post-merge
because the "recovered drawdown within the window" count is a knife-edge that
flipped the card in/out at short windows, making the board's card count
non-deterministic. `recovery_days` remains in `src/stats` (exported + tested).

**Windowing.** Window-scoped metrics (performance, autocorr, streaks,
drawdown/drawup, VaR, win-rate, Sharpe, skew) re-scope on the existing
`1W/1M/3M/6M` toggle. **RSI and MACD are fixed-lookback oscillators** (14d /
12-26-9) evaluated at the window end — they reflect current momentum and are
**intentionally unaffected** by the toggle. At very short windows (1W) the
window-scoped MACD/recovery/skew may be NaN; the existing NaN-skip in `add()`
drops those cards gracefully.

**New-stat definitions** (mirror the existing `src/stats` conventions —
per-ticker `pd.Series`, NaN-safe, deterministic):

- `return_autocorr(returns, *, window_days, lag=1)` — lag-1 Pearson
  autocorrelation of daily returns over the trailing window (>0 trending, <0
  mean-reverting). NaN for < ~`lag+3` valid points.
- `macd_histogram(prices, *, fast=12, slow=26, signal=9)` — MACD line =
  `EMA(fast) − EMA(slow)`; signal = `EMA(signal)` of the MACD line; histogram =
  MACD − signal, divided by the last price (so it's comparable across tickers);
  returns the last value per ticker (full-history, fixed lookback).
- `max_drawup(prices, years)` — mirror of `max_drawdown`: the max over the
  window of `price / running-min − 1` (largest run-up off a trough), per ticker.
- `recovery_days(prices, *, window_days)` — for each ticker's largest drawdown
  episode in the window, the number of days from the trough until price first
  regains the pre-drawdown peak; NaN if there is no drawdown or it hasn't
  recovered within the window. "Fastest recovery" = the min (single card only —
  no "slowest").
- `win_rate(returns, *, window_days)` — `mean(returns > 0)` over the window,
  per ticker.
- `return_skew(returns, *, window_days)` — per-ticker skewness of daily returns
  over the window (pandas `.skew()`); or reuse `return_distribution_stats`.
- `asset_class_demeaned_zscore(series, asset_class)` — subtract each asset
  class's mean from `series`, then z-score the demeaned series across the whole
  catalog (reuses `zscore_cross_section`). Returns a per-ticker z-Series used
  **only to rank** the **z**-flagged metrics; the displayed value stays the raw
  metric. This is what makes the board cross-asset-neutral: an index wins for
  being extreme *relative to its asset-class cohort*, not because its whole class
  is structurally high/low.

## 5. Alt-text (tooltip) rule

Every card's `description` (the hover tooltip) states **only how the metric is
calculated** — never what it implies. No "strong / weak / overbought / oversold
as opportunity / caution / wild". For **z**-ranked metrics the description also
names the ranking basis (that's methodology, not implication). Examples:

- RSI: "14-day Wilder RSI of daily closing levels." (not "strongest momentum")
- Performance: "Window price return (last ÷ first − 1); ranked across the
  catalog by its asset-class-demeaned z-score."
- VaR: "5th-percentile of daily returns over the window (historical 95% one-day
  VaR); ranked by asset-class-demeaned z-score."
- Autocorrelation: "Lag-1 Pearson autocorrelation of daily returns over the
  window."
- Recovery: "Days from the largest drawdown's trough until price regains its
  prior peak."
